# Control Autónomo: soporte y privacidad

Páginas públicas de Control Autónomo. Contacto: raulito-sp@hotmail.com.

## Publicar

1. Crea el repositorio público `Control-Autonomo-Web` en la cuenta `obreriyo`, con README.
2. Sube los archivos de este paquete en la raíz del repositorio. Deben verse `index.html`, `privacidad.html`, `eliminar-cuenta.html`, `estilos.css` e `icono-512.png`, sin una carpeta adicional que los envuelva.
3. En Settings → Pages, selecciona «Deploy from a branch», rama `main`, carpeta `/(root)` y guarda.
4. Espera a que termine `pages build and deployment` y abre las páginas sin iniciar sesión.

- Soporte: https://obreriyo.github.io/Control-Autonomo-Web/
- Privacidad: https://obreriyo.github.io/Control-Autonomo-Web/privacidad.html
- Eliminación: https://obreriyo.github.io/Control-Autonomo-Web/eliminar-cuenta.html

Mantén este repositorio público para que Google Play y los usuarios puedan abrir las páginas.
